## 3. 关键发现：StreamingAssets 下的 JSON 不能被 YooAsset 收集

用一次性探针在 batchmode 下检查 `Assets/StreamingAssets/Configs`：

```text
FindAssets count = 14
Assets/StreamingAssets/Configs/levels.json -> DefaultAsset
levels as TextAsset = False
levels main type = UnityEditor.DefaultAsset
```

原因：

- `StreamingAssets` 里的文件不会按普通资源导入，`.json` 的 `.meta` 使用 `DefaultImporter`；
- YooAsset 默认的 `NormalIgnoreRule` 会明确丢弃 `DefaultAsset`（并输出 `Cannot pack default asset` 警告）；
- 因此把收集路径直接指向 `Assets/StreamingAssets/Configs` 只会得到 0 个资源，`LoadAssetAsync<TextAsset>` 也拿不到文本。

对 M3.1 的要求：

1. 配置 JSON 需要迁到普通资源目录（本阶段先建了 `Assets/GameContent/Configs`）；
2. 迁移后编辑器工具（地图/技能/角色/怪物编辑器）的保存路径、`BattleConfigLoader` 的读取逻辑都要跟着改；
3. 迁移完成前不要删除 `StreamingAssets/Configs`，否则编辑器工具与旧流程会断。

## 6. HybridCLR 补齐

### 6.1 问题

首次 IL2CPP 构建失败：

```text
BuildFailedException: You have not initialized HybridCLR, please install it via menu 'HybridCLR/Installer'
```

原因：`HybridCLRSettings.asset` 只复制了配置，`Library/HybridCLR/LocalIl2CppData-WindowsEditor` 还没安装。

### 6.2 处理

`HybridCLR/Installer` 需要从 gitee 克隆 `hybridclr` 与 `il2cpp_plus`。本轮直接从同版本参考工程复制已安装好的本地 il2cpp 数据：

```powershell
robocopy "D:\Unity\UnityLearningProject\MonsterDungeon\Library\HybridCLR\LocalIl2CppData-WindowsEditor" `
         "D:\Unity\UnityLearningProject\PrismTactics\Library\HybridCLR\LocalIl2CppData-WindowsEditor" `
         /E
```

- 版本一致：`libil2cpp-version.txt` = `9.0.3`，与包版本 `9.0.3` 相同；
- 该目录在 `Library/` 下，不进仓库；换机器时重新执行 Installer。

然后执行 `Generate/All`：

```powershell
& "D:\Unity\2022.3.62f2c1\Editor\Unity.exe" -batchmode -nographics `
  -projectPath "D:\Unity\UnityLearningProject\PrismTactics" `
  -executeMethod "PrismTactics.EditorTools.Phase3HybridCLR.GenerateAllFromCli" `
  -logFile "Logs\m30_hybridclr_generate.log"
```

产物：

```text
Assets/HybridCLR/Generate/link.xml
Assets/HybridCLR/Generate/AOTGenericReferences.cs
Library/HybridCLR/LocalIl2CppData-WindowsEditor/il2cpp/libil2cpp/hybridclr/generated/MethodBridge.inc（DEVELOPMENT=0）
Library/HybridCLR/AssembliesPostIl2CppStrip/StandaloneWindows64/*.dll（45 个）
```

注意：`Generate/All` 会临时打一个 Player 来剥离 AOT DLL，耗时数分钟；改了热更程序集或切 development 后要重跑，否则构建期会提示 `MethodBridge.inc DEVELOPMENT flag inconsistent`。
