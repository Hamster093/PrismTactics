## 3. 关键实现

### 3.1 启动链路

`Assets/_Project/Scripts/Battle/Runtime/Content/ContentService.cs` + `BootstrapController.cs`

```text
Bootstrap.unity
  └── BootstrapController.Start
        └── StartCoroutine(ContentService.LoadAsync)
              ├── EditorSimulateMode（编辑器）/ OfflinePlayMode（Player）
              ├── InitializeAsync
              ├── RequestPackageVersionAsync
              ├── UpdatePackageManifestAsync
              ├── 预加载 .json → 文本字典
              └── BattleConfigLoader.SetPreloadedConfigs
        └── 成功：SceneManager.LoadScene("M1_Battle")
        └── 失败：停留 Boot，显示阶段/错误/重试
```

- 直接 Play `M1_Battle` / `M1_Perf60` 会明确报错“内容尚未加载，请从 Bootstrap 场景启动”，不会偷偷读旧文件。
- 新增菜单 `Tools > PrismTactics > 第三阶段 > 打开 Bootstrap 场景`。
- Boot 场景由 `Phase3BootstrapScene` 生成，并自动插入 Build Settings 第一个。

### 3.2 配置源与内容包

- 4 个编辑器窗口（地图/技能/角色/怪物）直接写 `Assets/GameContent/Configs`，不再经过镜像。
- `BattleConfigLoader.ConfigDirectory` 指向 `GameContent/Configs`，EditMode 测试和校验器都用它。
- `Phase3ContentBuilder` 用 `ScriptableBuildPipeline` 构建 `BattleRes 1.0.0`，并复制到
  `Assets/StreamingAssets/yoo/BattleRes`；Player 构建前会自动执行一次。
- `Assets/StreamingAssets/yoo/` 是产物，已加入 `.gitignore`。

### 3.3 配置读取

- `BattleConfigLoader.Load<T>` 先查预加载缓存。
- Play Mode 下缓存为空 → `LogError` 并返回 null（明确失败）。
- EditMode 测试 / 编辑器工具读 `GameContent/Configs` 文件，不依赖 YooAsset。

### 3.4 踩坑记录

1. **`InitializationOperation` 没有实现 `WaitForAsyncComplete`**
   旧实现用反射驱动 `YooAssets.Update()`，已删除；现在改为 Boot 场景协程，直接 `yield return` operation。
2. **Unity batchmode 收尾挂起**
   测试结果 XML 已写完后，`Unity.exe` 偶尔不退出；手动结束并删除 `Temp/UnityLockfile`，不影响项目。
3. **`GetAllAssetInfos()` 的 `AssetType` 为 null**
   不能按类型过滤，按 `.json` 后缀筛选。
