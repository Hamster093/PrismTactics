## 2. 地址规则

新增 `GameContentPathAddressRule`：去掉 `Assets/GameContent/` 前缀和扩展名。

```text
Assets/GameContent/UIPrefab/HUD.prefab            → UIPrefab/HUD
Assets/GameContent/UIHandDrawn/ui_life.png        → UIHandDrawn/ui_life
Assets/GameContent/DamageNumber.prefab            → DamageNumber
Assets/GameContent/MapVisual/Prefabs/...          → MapVisual/Prefabs/...
```

等于保留了旧 `Resources.Load` 路径，所以迁移时大部分调用点只换 Loader，不用重算地址。

## 3. AssetService

`Assets/_Project/Scripts/Battle/Runtime/Content/AssetService.cs`

```text
Load<T>       必需资源，失败 LogError
TryLoad<T>    可选 UI，缺失/类型不符静默返回 null
LoadComponent<T>  Prefab 根节点组件；YooAsset 主类型是 GameObject
ReleaseAll()  切版本/失败回滚时统一释放句柄
```

规则：

- Prefab 用 `Load<GameObject>` / `LoadComponent<T>`，不能直接 `Load<MonoBehaviour>`；
- HUD 图标、头像等允许缺失的用 `TryLoad`，不刷 Error；
- 配置、地图、单位目录等必须存在的用 `Load`。

## 4. 运行时调用点

| 资源 | 代码 |
|---|---|
| `UnitPrefabCatalog` | `BattleController`、`EnemyFactory` → `AssetService.Load` |
| `MapVisualConfig` | `BattleMapView` → `AssetService.Load` |
| `DamageNumber` | `DamageNumberManager` → `LoadComponent<DamageNumberView>` |
| `HealthBar` / `Projectile` | `UnitStatusBarFactory` / `ProjectileManager` → `Load<GameObject>` |
| UI 图标/立绘 | `BattleHudBinder` / `MetaFlowController` / `OperatorPortraitUtility` |

`OperatorPortraitUtility` 统一处理数字 ID → 立绘名，修掉了 `unit_<数字>_card` 拼不出资源的问题。

- 新增 `Phase3ResourceCollector`：幂等补全 CombatVFX / UI / MapVisual 收集器，地址规则统一。

- `UIHandDrawn` 只有一张 `skill_guard_power_strike`，其他技能图标本来就是缺失的；`TryLoad` 下不会报错，但图标仍为空，后续按需补资源或做 ID 映射。
- 旧的 `unit_guard_card` 等命名和数字 ID 不一致，现已统一走立绘映射；如果以后要卡面，按同样方式加映射。
