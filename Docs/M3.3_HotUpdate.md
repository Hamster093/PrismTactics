# M3.3 热更与正式内容 1.2.0

日期：2026-11-04  
对应版本：1.2.0

## 1. 本次更新内容

### BattleRes 1.2.0

- 新地图 `map_2` + `waves_2` + `battle_2`
- 第 6 关入口 + `LevelNode6`
- `DLC_02` 地面/高台/基地/出生点/背景 Prefab
- 新干员「黑骑士」+ 2 个技能
- 新敌人「黄金史莱姆」
- `MapVisualConfig_Map2`

### HotUpdateRes 1.2.0

- `HotUpdateEntry` 版本 1.2.0
- `Map2VisualProvider`：map_2 使用独立视觉配置
- `FrostNovaHandler`：黑暗物质的范围伤害 + 3 跳 DoT
- `HotUpdateSkillContext` / `HotUpdateTickService`：技能能力层

## 2. 热更边界

AOT 提供：

- `IHotUpdateEntry` / `OnRegister`
- `IMapVisualProvider`
- `ISkillEffectHandler` / `ISkillEffectContext`
- `HotUpdateTickService`
- `IHotUpdateVisualService`
- `CombatEntity` 运行时范围/攻速/属性修改

热更负责：

- 地图 ID → 视觉配置地址
- 技能效果组合
- DoT/弹幕/延迟逻辑
- 后续敌人/地图规则

## 3. 构建顺序

```text
1. HybridCLR Generate/All
2. 复制 PrismTactics.HotUpdate.dll → Assets/HotUpdateRes/*.bytes
3. 构建 HotUpdateRes 1.2.0
4. 构建 BattleRes 1.2.0
5. 写 release.json（latest=1.2.0，previous=1.1.0）
6. 构建 Player
```

构建后必须把包目录下所有 bundle 合并进 `BuildinCatalog`，否则旧版本 manifest 回滚会找不到 bundle。
