# PrismTactics M3.2：双包发布清单与回滚

日期：2026-11-01  
工程：`D:\Unity\UnityLearningProject\PrismTactics`  
前置：M3.1（配置走 YooAsset、Boot 场景、OfflinePlayMode 内容包）

---

## 1. 核心规则

```text
一个发布 = release.json 里的一条记录
           ├── battleResVersion
           ├── hotUpdateResVersion
           ├── hotUpdateDllHash（M3.3 填）
           └── releaseId（= 内容版本）
```

- 运行时只读 `release.json`，**不允许单独指定某个包的版本**。
- 回滚只改 `latest` / `previous` 指针，两个包一起回。
- `schemaVersion` 防止“新代码 + 旧配置”；`minAppVersion` 防止旧 Player 加载新内容。
- 显式 `--content-release` 只尝试指定版本，失败直接报错；默认 latest 失败才会自动回退 previous。

## 2. release.json

源文件：`Assets/GameContent/Release/release.json`（入库）  
Player 副本：`Assets/StreamingAssets/Release/release.json`（构建生成，不入库）

```json
{
  "appVersion": "0.1.0",
  "minAppVersion": "0.1",
  "schemaVersion": 1,
  "latest": "1.1.0",
  "previous": "1.0.0",
  "releases": [
    {
      "releaseId": "1.0.0",
      "battleResVersion": "1.0.0",
      "hotUpdateResVersion": "1.0.0",
      "hotUpdateDllHash": "",
      "note": ""
    },
    {
      "releaseId": "1.1.0",
      "battleResVersion": "1.1.0",
      "hotUpdateResVersion": "1.1.0",
      "hotUpdateDllHash": "",
      "note": ""
    }
  ]
}
```

## 3. 启动与回退流程

```text
ContentService.LoadAsync
  ├── 读 release.json（编辑器读 GameContent，Player 读 StreamingAssets）
  ├── 校验 schemaVersion / minAppVersion
  ├── 候选版本：--content-release 指定值，或 latest → previous
  ├── 对每个候选：
  │     ├── EditorSimulateMode：用 Simulate 清单
  │     ├── OfflinePlayMode：用 release 里钉住的 battleResVersion
  │     ├── 更新清单 → 预加载配置
  │     └── 失败则销毁 YooAssets，尝试下一个候选
  └── 全部失败：停在 Boot，显示阶段/错误/重试（不回退文件）
```

关键点：Player **不再**用本地 `BattleRes.version` 当作要加载的版本，而是用清单里的版本；否则回滚时会命中错误缓存。

## 4. 发布命令

```powershell
# 发布 1.0.0（首次，清空内置目录）
$env:PRISM_RELEASE_VERSION="1.0.0"
$env:PRISM_RELEASE_PREVIOUS=""
$env:PRISM_CONTENT_KEEP_BUILTIN="0"
& "D:\Unity\2022.3.62f2c1\Editor\Unity.exe" -batchmode -nographics -quit `
  -projectPath "D:\Unity\UnityLearningProject\PrismTactics" `
  -executeMethod "PrismTactics.EditorTools.Phase3ReleaseBuilder.PublishFromCli" `
  -logFile "Logs\m32_publish_100.log"

# 发布 1.1.0（保留 1.0.0 的内置清单，供回滚）
$env:PRISM_RELEASE_VERSION="1.1.0"
$env:PRISM_RELEASE_PREVIOUS="1.0.0"
$env:PRISM_CONTENT_KEEP_BUILTIN="1"
& "D:\Unity\2022.3.62f2c1\Editor\Unity.exe" -batchmode -nographics -quit `
  -projectPath "D:\Unity\UnityLearningProject\PrismTactics" `
  -executeMethod "PrismTactics.EditorTools.Phase3ReleaseBuilder.PublishFromCli" `
  -logFile "Logs\m32_publish_110.log"

# 校验
& "D:\Unity\2022.3.62f2c1\Editor\Unity.exe" -batchmode -nographics -quit `
  -projectPath "D:\Unity\UnityLearningProject\PrismTactics" `
  -executeMethod "PrismTactics.EditorTools.Phase3ReleaseBuilder.ValidateFromCli" `
  -logFile "Logs\m32_validate.log"
```

环境变量：

```text
PRISM_RELEASE_VERSION       发布版本号
PRISM_RELEASE_PREVIOUS      回滚目标
PRISM_RELEASE_APP           appVersion（默认沿用）
PRISM_RELEASE_MIN_APP       minAppVersion（默认沿用）
PRISM_HOTUPDATE_VERSION     HotUpdateRes 版本（默认同发布版本）
PRISM_CONTENT_KEEP_BUILTIN  1=保留旧内置清单，0=清空
```

## 5. 验收结果

| 场景 | 结果 |
|---|---|
| 正常启动 | `release=1.1.0，BattleRes=1.1.0` |
| 手动回退 | `--content-release 1.0.0` → `release=1.0.0，BattleRes=1.0.0` |
| 自动回退 | latest 改成不存在的 `9.9.9` → 记录不存在 → 自动加载 `1.0.0` |
| 显式版本不可用 | `--content-release 9.9.9` → 停在 Boot 报错，不回退 |
| 内置包 | `BattleRes_1.0.0.bytes` 与 `BattleRes_1.1.0.bytes` 同时存在 |
| PlayMode | 5/5（EditorSimulateMode 也读 release.json） |

## 6. 限制

- OfflinePlayMode 的回滚依赖内置目录同时存在旧版本清单；正式发布由构建机把两个版本一起打进 Player，或切 HostPlayMode 从 HTTP 拉取。
- `HotUpdateRes` 目前只钉版本号，DLL 加载和 hash 校验在 M3.3 接。
- 还没有“灰度/多版本并行”，只有 latest/previous 两档。
